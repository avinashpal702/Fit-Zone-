# FitZone

FitZone is a modern fitness studio website built with PHP and Bootstrap. It showcases training programs, coach profiles, and a contact form for new members.

## Overview

This project was created to present a clean and motivating fitness brand experience. The site includes:

- A strong landing page with a gym-focused hero section
- About page with studio mission and value proposition
- Programs page with training categories and details modal
- Trainers page with staff profile carousel
- Contact form with client-side validation
- Responsive layout for desktop and mobile devices

## Tech Stack

- PHP
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Run the Project Locally

1. Make sure PHP is installed on your machine.
2. Open a terminal in the project folder.
3. Run:

```bash
php -S 127.0.0.1:8000
```

4. Open your browser and go to:

```text
http://127.0.0.1:8000
```

## Features

- Responsive single-page style multi-page layout
- Modern fitness branding and imagery
- Primary navigation and call-to-action buttons
- Program cards with modal details
- Trainer carousel
- Form validation for enquiries

## Customization

You can update the branding, page text, or program content directly in the `.php` files and the `style.css` file.

## Notes

This project is intentionally lightweight and easy to extend for additional sections such as pricing, testimonials, membership plans, or booking workflows.
